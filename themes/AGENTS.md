# themes/: built-in theme packages

Each folder is one **theme**: a `theme.json` manifest plus its art. A theme
sets the wallpaper, colours, the decoration around the focused card, the
particles, Home's corner scene and what the visiting bears wear. **Designing
a theme means choosing, colouring and drawing; no code.**

- Guide: [`docs/THEMES.md`](../docs/THEMES.md) (start at
  [Make it yours](../docs/THEMES.md#make-it-yours)).
- Manifest spec: [`contracts/theme.schema.json`](../contracts/theme.schema.json).
- Terms: [`docs/GLOSSARY.md`](../docs/GLOSSARY.md).

## Key files

| Folder | Shows off | Art |
|---|---|---|
| [`den/`](den/theme.json) | vine + daisy, fireflies, den family; the fallback theme | wallpaper, phone backdrop, two sheets |
| [`forest/`](forest/theme.json) | fern + mushrooms (upright) + berries, leaves, camp scene | wallpaper, phone backdrop, two sheets |
| [`midnight/`](midnight/theme.json) | stars + moon tip, stars, moon scene | wallpaper, phone backdrop, one sheet |
| [`campfire/`](campfire/theme.json) | embers + upright flame tip, embers, campfire scene; alias `charcoal` | wallpaper, phone backdrop, four sheets |
| [`winter/`](winter/theme.json) | **the smallest complete theme**: pixel backdrop with an aurora and a cabin, its own `snowflake.png` ornament, snow, moon scene | wallpaper, phone backdrop, two sheets, one ornament |

A "sheet" is a sprite sheet: animation frames side by side in one PNG, listed
in `wallpaper.sprites`. All built-in art is generated by
[`tools/pixelart`](../tools/pixelart/README.md).
Each world also has Classic sheets (`classic-*.png`, listed in
`classic.wallpaper.sprites`), generated by
[`tools/classicart/layers.py`](../tools/classicart/README.md).

## Rules

- **The folder name is the id** (`^[a-z][a-z0-9-]{1,31}$`), and it must equal
  `id` in the manifest.
- **Manifests pick building blocks, never add behaviour.** If a theme needs
  something the engine can't do, add a building block for every theme
  ([`docs/THEMES.md` → Extending the engine](../docs/THEMES.md#extending-the-engine-new-building-blocks)).
  Engine code never checks theme ids (`if theme == "forest"`).
- **Ornaments** named in a manifest resolve from the theme's own folder first,
  then the built-ins in
  [`apps/tv-shell/assets/ornaments/`](../apps/tv-shell/assets/ornaments/).
- **Art:** pixel art like the built-ins: a 480×270 PNG wallpaper with
  `"pixel": true` and animated `sprites`, a 168×270 PNG phone backdrop, PNG
  ornaments of 7–16 px. The built-ins are generated by
  [`tools/pixelart/`](../tools/pixelart/README.md) (`worlds/<id>.py`);
  regenerate rather than hand-edit them. Only your own art or art we drew,
  never trademarked logos
  ([`docs/THEMES.md` → Art and brands](../docs/THEMES.md#art-and-brands)).
- **Performance:** a theme can only choose blocks that already obey the
  [performance rules](../docs/THEMES.md#performance-rules). Mind the
  `count` of ambient particles (max 40; the built-ins use 10–30).

## Add a theme

Your own theme does not need to live here: put it in the TV's themes folder
and nothing is rebuilt
([`docs/THEMES.md` → Make a theme in five minutes](../docs/THEMES.md#make-a-theme-in-five-minutes)).
To ship it as a **built-in**:

1. Copy [`winter/`](winter/) to `themes/<id>/` and edit `theme.json`
   (id, name, colours, building blocks).
2. Add `<id>` to `builtInOrder` in
   [`internal/themes/themes.go`](../internal/themes/themes.go) and
   `kBuiltInOrder` in
   [`ThemeRegistry.cpp`](../apps/tv-shell/src/ThemeRegistry.cpp). Keep the two
   lists identical. A built-in missing from them sorts after them by id.
3. Optional generated world: add `tools/pixelart/worlds/<id>.py` and the id
   to `WORLDS` in `tools/pixelart/build.py`
   ([`tools/pixelart/README.md`](../tools/pixelart/README.md)).
4. `make shell go`, then preview with
   `scripts/sandbox.sh shot --theme <id>` and look at the PNG.

Done when: the checks below pass and you looked at the screenshots.

## How built-ins are wired

- **Shell:** `apps/tv-shell/CMakeLists.txt` globs `themes/**` into the qrc at
  `:/themes/<id>/`.
- **Coordinator:** `embed.go` embeds `themes/` as `bdtv.Themes`.
- **Display order:** the built-ins come first, in the order of `builtInOrder`
  and `kBuiltInOrder` (above).

## Checks

```sh
build/bin/bear-den-tv themes validate themes/<id>   # schema, files, ornaments
go test ./internal/themes                           # every built-in must validate
make test-shell                                     # the shell loads them all
make shots                                          # every theme × main screens, then look
```
