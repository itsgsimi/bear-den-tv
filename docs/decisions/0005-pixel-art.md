# ADR 0005 — Pixel art everywhere, generated from code

Date: 2026-09-23. Status: accepted; amended by [ADR 0006](0006-classic-art-style.md) (a Classic art style beside pixel art).

The owner asked for pixel-art scenes instead of the vector/photo look, for
everything: worlds, bears, decorations, chrome and the phone.

**Decision.**
- One grid: `World.px` art pixels (4 screen pixels at 1080p, a 480×270
  world). Every pixel-art item snaps to it and is drawn unsmoothed at a
  whole-number scale; nothing pixel-art is rotated or scaled in between.
- Worlds are theme data: `wallpaper.pixel` and `wallpaper.sprites` (additive
  under protocol 1, ADR 0004); phones get `state.appearance.pixel`.
- Procedural drawing (corner decorations, brand backdrops, boxes) stays
  Canvas/QPainter with no shaders, painted at 1/`World.px` of its size without
  antialiasing and shown scaled up; rounded `Rectangle`s became `PixelBox`.
- The art is generated by `tools/pixelart` from code with the Python standard
  library, deterministically, and the PNGs are committed. No image editor or
  Pillow is needed to change it.
- Text, owner brand art and the QR code stay smooth. (2026-09-28: Bear Den now draws its own app icons as pixel art too; official icons are used only from the owner's brand folder or for an adapter without a Bear Den icon. See [`THEMES.md` → App icons](../THEMES.md#app-icons).)

**Consequences.** Low-resolution canvases paint far fewer pixels than the
vector ones did. A full-screen animated layer (Campfire's rain) costs a blend
per frame while awake; it stops while resting like every loop. The corner
scene area grew to 110×82 art pixels (440×330) so the bears fit at one art
pixel per `World.px`. Owner themes may still use photos and SVG ornaments;
they draw smooth.

**How to change the art:** [`tools/pixelart/README.md`](../../tools/pixelart/README.md)
(every generator, what it writes, recipes) and
[`docs/THEMES.md` → Draw new pixel art](../THEMES.md#draw-new-pixel-art).
